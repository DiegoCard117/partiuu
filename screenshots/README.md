# Capturas de tela

Adicione nesta pasta as seguintes imagens em formato PNG, com aproximadamente 1080 px de largura, em formato de tela de celular:

| Arquivo | Tela |
| --- | --- |
| `hoje.png` | Hoje |
| `roteiro.png` | Roteiro por dia |
| `gastos.png` | Gastos e acerto de contas |
| `roteiro-sugerido.png` | Revisão do roteiro sugerido por IA |
| `mapa.png` | Mapa da viagem |

Use uma viagem de exemplo com dados fictícios. Não deixe e-mail, nome real, foto de pessoa ou documento real visível na tela.

Antes de salvar cada captura, confira também a barra de status: ela não deve mostrar notificações pessoais.

Mantenha os nomes exatamente como estão na tabela para que as imagens apareçam no README principal.
